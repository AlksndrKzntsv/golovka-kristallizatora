# Головка кристаллизатора ВЗД.01.03.03.007

Интерактивная 3D-модель детали по чертежу ВЗД.01.03.03.007 (ЛС59-1 ГОСТ 15527-2004).

**Открыть модель:** https://alksndrkzntsv.github.io/golovka-kristallizatora/

Возможности страницы:

- поворот модели вокруг осей X и Y, стандартные виды (главный, А, Б, снизу), вращение мышью;
- разрезы по трём осям с регулировкой положения плоскости и выбором удаляемой стороны;
- выгрузка модели в STL (размеры в миллиметрах).

Резьбы М56×2, М52×1,5, М35×1 и М27×1,5 смоделированы винтовыми, с метрическим профилем 60°.
Притупление кромок R0,2–0,3 не моделировалось.

Страница работает в современном браузере и ничего не требует устанавливать.
